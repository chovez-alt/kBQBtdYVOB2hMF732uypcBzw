# EKY Cologne

EKY Cologne is an installable phone-friendly PWA built from the MYS Wholesale master catalog v183.

## Included
- 1,027 catalog rows
- Search by MYS name, original inspiration, fragrance notes, or gender
- Men / Women / Unisex / Unresolved filters
- Verified-only filter
- Favorites saved on the device
- Inventory quantities and tote locations
- Full inventory editor for cologne name, exact quantity, and tote location
- A–Z / Z–A inventory sorting
- Sales deductions, low-stock alerts, and weekly/monthly sales tracking
- Quick Sell button on every inventory row with a quantity picker
- What’s New review queue and live MYS list updater
- Match Updated Catalog button that checks every unverified What’s New item, adds confirmed matches, and leaves uncertain items for review
- Per-fragrance Paste button that maps ChatGPT inspiration, notes, gender, confidence, reason, and source into the catalog entry
- Verify All matching, verified-only Add All, and manual verification controls
- Search ChatGPT handoff for unverified fragrance matching
- Search All ChatGPT and bulk result import matched by source ID
- Full fragrance detail sheet
- Catalog stats
- Offline catalog, inventory, tote, and sales access after the first successful load
- Update/refresh button
- iPhone Home Screen support
- Share button

## Publish
Upload this folder to Vercel as a static site. The included `vercel.json` is ready to use.

## iPhone install
1. Open the published EKY Cologne URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.

Catalog source: MYS Master Catalog v183.
